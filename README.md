## Overview

An interactive architecture diagram for a CRM Work Portal desktop application built with Electron, Node.js, PostgreSQL, Redis, and Mermaid.js.

## Features

* Interactive Mermaid.js architecture diagram
* Flow simulation with animated data paths
* Color-coded connection layers
* Sidebar legend for wire colors
* Auto-update workflow visualization
* Responsive and modern UI

## Architecture Layers

* Frontend (HTML, CSS, JavaScript)
* Authentication (SSO, JWT, RBAC)
* Electron Services
* Backend API (Node.js, Express)
* Feature Services
* Real-Time Communication (WebSockets)
* Background Processing (BullMQ, Redis)
* Data Layer (PostgreSQL, Neon, S3)
* Cache Layer (Redis)
* Observability (Logging, Monitoring)
* CI/CD Pipeline (GitHub Actions)

## Usage

Open `index.html` in your browser and click **Run Flow Simulation** to visualize the system workflow.
